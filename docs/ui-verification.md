- 首次加载动画属性独立拼接，确保应用名称单元格始终存在。

## 代码评审

- 所有动态名称、状态、网络、端口与属性值统一转义；协议只映射到固定 CSS 类，避免注入。
- 先完成新行 HTML 计算，再更新页面数据，减少异常导致的半更新状态。
- 请求超时计时器在 finally 清理；自动刷新计时器切换时先清理；删除已不存在容器的展开状态。
- 手机与电脑使用同一份 DOM，避免重复数据源、重复事件处理和展示规则漂移。
- 没有新增第三方依赖，没有修改 Docker 接口或端口扫描逻辑。
